## 3. Font-scale — FIXED (`38cc93a`)

`GoopText` renders plain `Text`; `main.dart`'s builder already replaces
the system textScaler with `TextScaler.linear(prefs.textScaleFactor)`
— so `VisualPrefs.fontSize` was the ONLY scale source, clamped 6–32pt
(2.3× — inside the danger zone).

**Shipped hardening (three layers):**
- `main.dart`: `textScaleFactor.clamp(0.8, 1.4)` — global cap, guards
  stale prefs too
- `VisualPrefs.fontSize` clamp 32→20pt (slider honestly matches ~1.43×)
- `maxLines:1 + ellipsis` on worst fixed heights: heister name/status
  (84px slot), browse ADD-strip label

**Break thresholds for future work:**

| Scale | What breaks |
|---|---|
| ~1.3–1.5× | Horizontal clipping where no ellipsis set — heister names, pill labels, fixed-width chips |
| ~1.5–2× | Fixed-height vertical clipping — heister slot (84px), ADD strip (56px), tier chips (34px) |
| ~2.2×+ | Search field (44px), button labels |

**Rule for new UI:** fixed-height containers MUST use
`maxLines`/`overflow` or `FittedBox` — the 1.4× cap protects today,
but ellipsis is the durable defense.

## 4. Field bugs found & fixed (`71d9d66`)

- **Detail view blank body** — root cause was the `bottomNavigationBar`'s
  bare `Center` expanding to eat all screen height (body got 0px). Fix:
  `Align(topCenter, heightFactor: 1)` shrink-wraps vertically; body uses
  `LayoutBuilder`+`SizedBox` for the width cap. Same `Center` landmine
  fixed in browse's search row. **Rule: `Center`/`Align` without
  `heightFactor`/`widthFactor` expands to fill — never use inside
  bottomNav/non-flex Column slots.** Smoke tests assert scrollview
  height>100: `test/_smoke_detail_test.dart`.
- **Browse ADD strip** — baked-in 62px block replaced with vertical
  separator + circular plus button (check when in-run).
- **Avatar white border** — 1–2px gridline edges baked into sliced
  portraits; mitigated with `Transform.scale(1.06)` inside `ClipRRect`
  in `FramedAvatar`.
- **Similar-pattern sweep** — no other `Center`/`ConstrainedBox`
  wrapping scrollables found; collapse was a one-off.
