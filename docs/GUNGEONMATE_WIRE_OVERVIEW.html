Technical Stack

Core Architecture

Built with Flutter SDK using Dart. Provides full native execution speed and zero rendering latency.

State Management

Uses Provider / ChangeNotifier streams. Emits precise localized state ticks only when inventory or stats mutate.

Double-Buffered Save

Utilizes multi-threaded isolates to save active runs asynchronously to SharedPreferences, complete with secondary fail-safe backups.

Canvas Theme Render

Custom visual engines (Drip, Wobble, Sheen) are calculated mathematically on Canvas. Requires 0MB of external asset footprints.
