1. Codex: Collapsible Bookmark Tab Strip

SHIPPED Collapsible Ammonomicon Tab Strip

The left-side bookmark tabs can now be collapsed to give the codex content the full screen width. A chevron toggle sits at the top of the strip. When collapsed, a small accent-colored tab remains so users can expand the strip back. The content area animates its left padding smoothly.

Lottie bookmark concept (proposed)

When the strip collapses, a Lottie animation of a bookmark sliding behind the content edge could play — giving the "tucking into a book" feeling. The expand would reverse the animation. This would require adding lottie: ^3.x to pubspec and creating a 2-3 second Lottie JSON. Low priority — the current chevron toggle works cleanly.

3. Visual Attention Items

A few items worthy of visual attention for future polish passes. Not implemented yet — just flagged here for review.

1. Codex Detail: Hero transition for NPC GIFs

PROPOSED

When tapping an NPC card, the idle GIF could fly from the card to the detail screen's hero area using a Hero animation. This would give a seamless "zoom into the character" feel. Requires wrapping the GIF in a Hero widget with a unique tag per NPC.

Card → Detail: GIF flies and scales up

2. Boss idle animations (assets/animations/bosses/)

ATTENTION

The assets/animations/bosses/ folder exists and is declared in pubspec, but we haven't checked what's in it or whether boss codex entries could use animated sprites like NPCs do. Worth investigating for consistency.

Boss tab → animated boss sprites?

3. Enemy idle animations (assets/animations/dog/)

ATTENTION

The assets/animations/dog/ folder exists and is declared in pubspec. If it contains enemy idle sprites, the same pattern used for NPCs could be applied to the Enemies tab.

Enemy tab → animated enemy sprites?

4. Active tab glow pulse

PROPOSED

The active bookmark tab currently has a static glow. A subtle breathing pulse (opacity 0.35 → 0.5 → 0.35 over 2s) would make the selected category feel alive without being distracting. Low priority — the static glow already reads well.

▒▒▒ breathing glow on active tab ▒▒▒

5. Search bar: animated focus state

PROPOSED

When the search bar gains focus, the border could animate from 0.3 alpha to 0.7 alpha with a subtle width change. Currently this is a hard transition. A 200ms ease would smooth it. Trivial fix.

🔍 Search enemies... [focus → border glows]

6. Collapsed tab: show active category color

SHIPPED

When the tab strip is collapsed, the small chevron button uses the active category's accent color. This gives users a visual hint of which section they're in even when the full strip is hidden.
