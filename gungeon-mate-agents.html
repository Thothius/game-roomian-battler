PARALLEL · Slot 3

A second pair of hands for parallel feature work.
Specialty: Whatever CORE isn't doing. Picks up independent features, bug fixes, or UI rework that doesn't overlap with Slot 2's active files.
Directive: Multiplies throughput when 2+ features need to ship in parallel. Coordinates with CORE via the status board and AC4 file locks.
Owns: Same domain as CORE — but only files NOT in CORE's "Files in progress" list
Does NOT touch: Any file claimed by another active slot. Uses worktree isolation (AC5d) when 2+ agents are active.
